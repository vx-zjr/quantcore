# QuantCore · 个人量化中心

一个**可视化、可交互、由 AI 持续迭代**的个人量化知识中心。

当前处于 **阶段 0：认知与地基** —— 不写策略代码，先系统建立做个人量化所需的
知识、技能、行业认知、信息源、思维框架与路线图。

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

开发模式下，界面上的操作会**直接写回 Markdown 文件**：
- 标记知识/思维/信息源的进度（未开始 / 进行中 / 已完成）
- 给技能打分（当前等级 / 目标等级）
- 给信息源评分、调整重要度
- 勾选路线图与日志中的任务项
- 随手记录想法到收件箱

`npm run build` 生成只读的静态站点（`dist/`），可部署到任何静态托管。

## 设计理念：内容即数据

```
content/**/*.md   ← 唯一数据源（YAML frontmatter + Markdown 正文）
      │
      ├── scripts/content/loader.ts   解析、校验、反向链接、健康检查
      ├── content/INDEX.md            自动生成的全局目录（AI 先读它）
      └── virtual:content ──▶ React 界面（只负责渲染与交互）
```

- **对 AI 友好**：每个知识点是一个独立的文本文件，AI 用普通的读写就能维护；`git diff` 让每次修改可审阅、可回滚。
- **有客观的完成标准**：`npm run check` = 重建索引 + schema 校验 + 链接完整性 + 类型检查。
- **可扩展**：枚举值（领域、市场、形态等）都在 `content/_meta/taxonomy.yaml`，新增无需改代码。

## 和 AI 一起迭代

所有 AI 工具（Claude Code、Codex、Cursor……）都遵循 [`AGENTS.md`](./AGENTS.md)。常见用法：

- 「按 playbooks/process-inbox.md 处理收件箱」
- 「复核所有过期节点」（playbooks/review-stale.md）
- 「新增一个关于 XX 的知识节点」（playbooks/add-node.md）
- 「做本周复盘」（playbooks/periodic-review.md）
- 「问我几个问题，帮我把 profile.yaml 填完」

界面中每个节点详情页、「内容维护」页都有「复制 AI 指令」按钮。

Claude Code 用户还可以直接使用 `/add-node`、`/process-inbox`、`/review-stale`、`/periodic-review`。

## 第一步做什么

1. 填写 `content/_meta/profile.yaml`（或让 AI 问你问题后代填）。
2. 在「技能」页对照等级标准给自己打分。
3. 按「路线图 → 阶段 0」的清单推进，从标记为「核心」的思维与知识节点开始读。

## 命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动开发服务器（可编辑） |
| `npm run check` | 完整校验（索引 + 内容 + 类型） |
| `npm run content:check` | 仅内容校验 |
| `npm run content:index` | 重建 `content/INDEX.md` |
| `npm run content:new -- <kind> <id> "标题"` | 从模板新建节点 |
| `npm run build` | 构建静态站点 |
