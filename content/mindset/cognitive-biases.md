## 研究阶段的偏差

| 偏差 | 表现 | 对策 |
|---|---|---|
| 确认偏误 | 只找支持自己想法的证据 | 预注册检验标准；主动寻找反例 |
| 叙事谬误 | 为数据结果编一个好听的故事 | 先有假设后看数据；故事要能推出新的可检验预测 |
| 幸存者偏差 | 只看到活下来的股票/基金/策略 | 使用包含退市股票的数据；记录失败的研究 |
| 后见之明 | 「这次暴跌我早该看出来」 | 决策前写下判断，事后对照 |
| 锚定 | 被第一个回测结果锚定 | 先定基线和标准，再看结果 |
| 沉没成本 | 研究投入了很多时间，舍不得放弃 | 设定研究的止损：N 小时内达不到标准就放弃 |

## 交易阶段的偏差

| 偏差 | 表现 | 对策 |
|---|---|---|
| 损失厌恶 | 亏损的痛苦约为同等盈利快乐的两倍，导致不敢止损或过早止盈 | 规则化出场 |
| 处置效应 | 卖出赚钱的、拿着亏钱的 | 系统化持仓 |
| 近因效应 | 用最近几周的表现判断策略好坏 | 用足够长的窗口评估；理解策略的正常波动范围 |
| 过度自信 | 高估自己的预测能力，过度交易、加杠杆 | 仓位上限写死；记录预测准确率 |
| 控制错觉 | 盯盘、手动干预让人觉得更安全 | 减少看盘频率；记录每次手动干预及其结果 |
| 赌徒谬误 | 「连亏了这么多次，下次该赢了」 | 理解独立性；看统计而不是看感觉 |

## 在量化中的体现

系统化交易的核心价值之一，就是**在冷静时把决策写成规则，在情绪化时只负责执行**。
但量化并不能消除偏差——它只是把偏差从交易环节转移到了研究环节（尤其是过拟合）。

## 自检问题

- 最近一次手动干预系统是什么时候？结果比不干预好吗？
- 我是否在用「这次不一样」来解释为什么要违反规则？
