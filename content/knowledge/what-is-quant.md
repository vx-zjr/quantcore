## 一句话

**量化交易 = 把「什么时候买、买什么、买多少、什么时候卖」写成明确的规则，用历史数据检验这套规则过去是否有效，然后严格按规则执行。**

规则可以很简单（「指数在 200 日均线之上就持有，之下就空仓」），也可以很复杂（几百个因子 + 机器学习）。关键不在复杂，而在**明确、可检验、可重复**。

## 和「凭感觉炒股」有什么不同

| | 主观交易 | 量化交易 |
|---|---|---|
| 决策依据 | 经验、直觉、消息 | 事先写好的规则 |
| 能否检验 | 很难知道过去这样做是否有效 | 可以在历史数据上回测 |
| 执行 | 容易受情绪影响 | 按规则执行（理想情况下） |
| 主要风险 | 情绪、偏见、不一致 | 过拟合、模型失效、程序错误 |

量化不会消除人的弱点，只是把它从「交易时」转移到了「设计规则时」——最大的敌人变成了**自欺欺人的回测**（参见 [[overfitting-is-default]]）。

## 一个策略的一生

```
想法 → 找数据 → 写规则 → 回测（在历史上试）→ 模拟盘（用实时数据但不花钱）→ 小资金实盘 → 持续监控
```

大部分想法在「回测」这一步就应该被淘汰。详见 [[alpha-research-pipeline]]。

## 量化「不是」什么

- **不是印钞机**：多数人（包括专业机构）的超额收益很难长期维持。2026 年 7 月国内量化私募就出现了行业性大幅回撤。
- **不是一定要高频**：高频是机构的速度竞赛，个人的机会在中低频（参见 [[small-player-edge]]）。
- **不是 AI 自动赚钱**：AI 是很好的学习和编程助手，但不能替你判断一个策略是真有效还是碰巧好看。
- **不是回测好就能赚钱**：回测好看太容易了，难的是证明它不是巧合（参见 [[base-rates]]）。

## 零基础需要学哪三样

1. **编程**：用 Python 处理数据——这是你的「手」（[[python]]、[[pandas-numpy]]）。
2. **统计**：判断一个结果是信号还是噪声——这是你的「眼」（[[probability-statistics]]）。
3. **市场知识**：知道规则、成本、谁在和你交易——这是你的「地图」（[[market-knowledge]]、[[cn-a-share-rules]]）。

另外还有一样不需要基础、但最重要的：**正确的思维方式**（本中心「思维」板块）。

## 现实的预期

- 以每周 20 小时计，从零到「能独立做一个可信的简单研究」通常需要 6–12 个月。
- 第一年的目标是**学会判断**，不是赚钱。在研究流程可靠之前，不投入真钱是对的。
