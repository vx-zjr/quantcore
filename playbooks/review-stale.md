# Playbook：复核过期 / 时效性内容

触发：`npm run content:check` 报告「已过复核日期」，或节点 `confidence: low`，或用户要求核实。

量化领域的规则、费率、监管、机构格局、数据源政策变化很快。过期内容比没有内容更危险。

## 步骤

1. **列出待复核节点**：`npm run content:check` 中带「已过复核日期」的条目，或 UI「内容维护」页。
2. **逐个核实**正文中的时效性陈述：
   - 交易规则、费率、税率 → 交易所/监管机构官网公告
   - 监管规定 → 证监会、交易所官网原文
   - 机构与行业格局 → 多个独立来源交叉验证
   - 数据源/工具 → 官网、GitHub 仓库的最近更新时间与许可变化
   - 能联网就查一手来源；**不能联网时不要凭记忆"更新"**——只把 `confidence` 降为 `low` 并在正文注明「需联网核实」。
3. **更新**：
   - 修正过时内容，正文中注明「截至 YYYY-MM」。
   - 已核实：`confidence` 视来源质量设为 high/medium；`review` 顺延（规则类 6 个月，格局类 6-12 个月，原理类可移除 review）。
   - 更新 `updated`。
4. **影响面**：搜索引用该节点的其他节点（看 INDEX.md 或节点的「被引用」），确认没有连带过时的说法。
5. **验证与记录**：`npm run check`；CHANGELOG 中列出核实了什么、改了什么、依据是什么。
